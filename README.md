# frontend-react

This ZIP preserves the existing Create React App project and adds the component folders/files shown in your VS Code screenshot.

## Run the project

1. Extract the ZIP and open the `frontend-react` folder in VS Code.
2. Run `npm install` if needed.
3. Run `npm start`.

Open `http://localhost:3000/login` to view the Account Login screen. Open `http://localhost:3000/` to view the component demo.

The login form currently demonstrates the UI and browser-side required-field validation; it is not connected to an authentication backend.
